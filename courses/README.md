# 강의 자료 (Course Materials)

이 디렉토리는 체계적인 강의 자료를 포함합니다.
This directory contains structured course materials.

## 📖 사용 가능한 강의 (Available Courses)

각 강의는 별도의 디렉토리로 구성되며, 다음을 포함합니다:
- 강의 계획서 (Syllabus)
- 강의 노트 (Lecture notes)
- 슬라이드 (Slides)
- 실습 예제 (Practice examples)

Each course is organized in a separate directory and includes:
- Syllabus
- Lecture notes
- Slides
- Practice examples

## 📝 강의 추가 가이드 (Guide to Adding Courses)

새로운 강의를 추가할 때는 다음 구조를 따라주세요:

```
course-name/
├── README.md          # 강의 개요
├── syllabus.md        # 강의 계획서
├── week-01/           # 주차별 자료
│   ├── lecture.md
│   ├── slides.pdf
│   └── examples/
├── week-02/
└── ...
```

When adding a new course, please follow this structure:
- Clear course overview in README.md
- Detailed syllabus
- Weekly organized materials
- Code examples and exercises
