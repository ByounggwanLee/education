## 🎯 실습 진행 방법

### 준비사항
- ✅ Git 설치 완료
- ✅ GitHub 계정 생성
- ✅ 텍스트 에디터 또는 IDE 준비 (VS Code 권장)
- ✅ 터미널/명령 프롬프트 사용 가능

### 실습 환경
각 실습은 독립적으로 진행할 수 있도록 구성되어 있습니다.

```bash
# 실습용 디렉토리 생성
mkdir git-practice
cd git-practice
```

### 실습 팁
- 📝 명령어를 직접 타이핑하면서 익히세요
- 🔍 각 명령어 실행 후 `git status`로 상태 확인
- 💡 에러가 발생하면 메시지를 잘 읽어보세요
- 🤔 이해가 안 되면 반복해서 연습하세요
- ✨ 실습 후에는 본인만의 프로젝트에 적용해보세요

## 🗂️ 실습 예제 파일

각 실습에는 예제 파일들이 포함되어 있습니다:
