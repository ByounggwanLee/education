## 💡 학습 팁

1. **직접 타이핑하세요**
   - 복사/붙여넣기 대신 직접 명령어 입력
   - 타이핑하면서 익숙해집니다

2. **자주 `git status` 확인**
   - 현재 상태를 항상 확인하는 습관
   - 실수 예방

3. **실수를 두려워하지 마세요**
   - Git은 거의 모든 것을 복구 가능
   - 실습 환경에서 자유롭게 실험

4. **문서를 활용하세요**
   - 막히면 FAQ 참조
   - 치트시트를 옆에 두고 학습

5. **실제 프로젝트에 적용**
   - 개인 프로젝트부터 Git 사용
   - 습관이 되어야 합니다
