## 🔍 Git 내부 동작 이해

### 필수 아티클
- **Git Internals**: https://git-scm.com/book/en/v2/Git-Internals-Plumbing-and-Porcelain
- **Git from the Bottom Up**: https://jwiegley.github.io/git-from-the-bottom-up/
- **Learn Git Internals by Building Your Own Git**: https://www.leshenko.net/p/ugit/

### 실험해보기
```bash
# .git 디렉토리 탐색
cd .git
ls -la

# Git 객체 확인
git cat-file -p HEAD
git ls-tree HEAD

# Pack 파일 분석
git verify-pack -v .git/objects/pack/*.idx
```

## 💡 학습 팁

### 효과적인 학습 방법
1. **매일 사용하기**: 개인 프로젝트라도 Git 사용
2. **실수하기**: 안전한 환경에서 실험
3. **커뮤니티 참여**: 질문하고 답변하기
4. **오픈소스 기여**: 실제 프로젝트 경험
5. **블로그 작성**: 배운 내용 정리

### 피해야 할 실수
- ❌ GUI만 사용 (CLI도 익히기)
- ❌ `--force` 남용
- ❌ 큰 파일 커밋
- ❌ 민감 정보 커밋
