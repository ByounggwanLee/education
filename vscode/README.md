# VS Code 완벽 가이드

프로젝트 개발자를 위한 Visual Studio Code 학습 자료입니다.

## 📋 대상

- 프로젝트 개발자
- Spring Boot, React, Git을 사용하는 개발팀

## 🎯 학습 목표

이 과정을 통해 다음을 학습할 수 있습니다:

- VS Code 설치 및 기본 환경 설정
- 프로젝트별 필수 확장 프로그램 설치 및 활용
- Spring Boot(Gradle/Maven) 프로젝트 개발
- React(Vite) 프로젝트 개발
- 컴파일, 실행, 디버깅, 빌드 방법
- 원격 디버깅 설정 및 활용
- Git, GitLens, Git History를 활용한 버전 관리
