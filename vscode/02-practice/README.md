# 실습 Lab

VS Code 사용법을 직접 따라하며 익히는 실습 과정입니다.

## 실습 목차

### 기초 과정

1. **[Lab 1: VS Code 설치 및 설정](lab01-installation.md)**
   - VS Code 설치
   - 기본 설정 구성
   - 필수 확장 프로그램 설치
   - 워크스페이스 설정

2. **[Lab 2: Spring Boot 프로젝트 시작하기](lab02-springboot-project.md)**
   - Spring Boot 프로젝트 생성
   - 기본 CRUD API 구현
   - 실행 및 테스트

3. **[Lab 3: React 프로젝트 시작하기](lab03-react-project.md)**
   - Vite로 React 프로젝트 생성
   - 컴포넌트 작성
   - API 연동

### 중급 과정

4. **[Lab 4: 디버깅 실습](lab04-debugging.md)**
   - 중단점 설정 및 활용
   - 변수 검사
   - 조건부 중단점
   - Java 및 JavaScript 디버깅

5. **[Lab 5: 원격 디버깅 실습](lab05-remote-debugging.md)**
   - Docker 컨테이너 디버깅
   - 원격 서버 디버깅
   - SSH를 통한 원격 개발

6. **[Lab 6: Git 활용 실습](lab06-git-workflow.md)**
   - Git 기본 워크플로우
   - 브랜치 관리
   - 충돌 해결
   - GitLens 활용

### 통합 과정

7. **[Lab 7: 풀스택 프로젝트 실습](lab07-full-stack-project.md)**
   - Spring Boot 백엔드 개발
   - React 프론트엔드 개발
   - 통합 디버깅
   - 배포 준비

## 실습 환경 요구사항

### 소프트웨어

- **VS Code**: 최신 버전
- **JDK**: 17 이상
- **Node.js**: 18 이상
- **Git**: 최신 버전
- **Docker**: 선택사항 (Lab 5용)

### 하드웨어

- **RAM**: 8GB 이상 권장
- **디스크 공간**: 10GB 이상 여유 공간
- **인터넷**: 패키지 다운로드용

## 실습 진행 방법

### 1. 순차적 학습

Lab을 순서대로 진행하는 것을 권장합니다. 각 Lab은 이전 Lab의 내용을 기반으로 합니다.

### 2. 실습 파일 준비

각 Lab에서 제공하는 코드를 직접 입력하며 학습합니다.

### 3. 문제 해결

실습 중 문제가 발생하면:
1. 에러 메시지 확인
2. Lab 내용 다시 확인
3. [FAQ](../03-reference/faq.md) 참고
4. 구글 검색 활용

### 4. 확인 문제

각 Lab 마지막에 있는 확인 문제를 풀어보세요.

## 실습 팁

### ✅ 직접 입력하기

코드를 복사-붙여넣기 대신 직접 입력하면 자동완성과 IntelliSense를 경험할 수 있습니다.

### ✅ 에러 경험하기

의도적으로 에러를 발생시켜보고 해결하는 연습을 하세요.

### ✅ 단축키 사용하기

마우스 대신 단축키를 사용하여 생산성을 높이세요.

### ✅ 확장 프로그램 탐색

실습에 나온 것 외에도 유용한 확장을 찾아보세요.
