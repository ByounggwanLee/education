# 연습 문제 (Exercises)

이 디렉토리는 실력 향상을 위한 연습 문제를 포함합니다.
This directory contains exercises to improve your skills.

## 💪 연습 문제 난이도 (Exercise Difficulty Levels)

- **초급 (Beginner)**: 기본 개념 익히기
- **중급 (Intermediate)**: 실전 응용 연습
- **고급 (Advanced)**: 복잡한 문제 해결

Difficulty levels:
- **Beginner**: Learning basic concepts
- **Intermediate**: Practical applications
- **Advanced**: Complex problem solving

## 📋 연습 문제 구조 (Exercise Structure)

각 연습 문제는 다음을 포함합니다:

```
exercise-name/
├── README.md          # 문제 설명
├── problem.md         # 상세한 문제 정의
├── starter-code/      # 시작 코드
├── solution/          # 해답 (감춰진 폴더)
└── tests/             # 테스트 케이스
```

Each exercise includes:
- Problem description
- Detailed requirements
- Starter code
- Solution (in a hidden folder)
- Test cases

## 🎓 학습 방법 (How to Practice)

1. 문제를 읽고 이해하기
2. 스스로 해결 시도하기
3. 막힐 때는 힌트 확인하기
4. 테스트 케이스로 검증하기
5. 해답과 비교하며 학습하기

Practice approach:
1. Read and understand the problem
2. Try solving it yourself
3. Check hints if stuck
4. Verify with test cases
5. Learn by comparing with solutions
