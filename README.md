## 개요 (Overview)

이 저장소는 다양한 교육 자료를 효과적으로 관리하고 공유하기 위해 만들어졌습니다. 
프로그래밍, 데이터 과학, 웹 개발 등 다양한 주제의 교육 자료를 포함할 수 있습니다.

This repository is created to effectively manage and share various educational materials.
It can include educational resources on various topics such as programming, data science, web development, and more.

## 디렉토리 구조 (Directory Structure)

```
education/
├── courses/           # 강의 자료 (Course materials)
├── tutorials/         # 튜토리얼 (Tutorials)
├── exercises/         # 연습 문제 (Exercises)
├── resources/         # 참고 자료 (Reference materials)
└── projects/          # 프로젝트 (Projects)
```

## 사용 방법 (How to Use)

### 자료 찾기 (Finding Materials)

1. 원하는 주제의 디렉토리로 이동하세요
2. 각 디렉토리의 README를 참고하여 자료를 확인하세요
3. 필요한 자료를 다운로드하거나 복제하세요

### 자료 추가하기 (Adding Materials)

1. 이 저장소를 포크(Fork)하세요
2. 새로운 브랜치를 생성하세요
3. 자료를 추가하고 커밋하세요
4. 풀 리퀘스트(Pull Request)를 생성하세요

## 기여하기 (Contributing)

교육 자료 기여를 환영합니다! 다음 가이드라인을 따라주세요:

- 명확하고 이해하기 쉬운 자료를 작성하세요
- 적절한 디렉토리에 자료를 배치하세요
- 각 자료에 대한 설명을 README에 추가하세요
- 코드 예제는 잘 주석 처리하세요

We welcome contributions of educational materials! Please follow these guidelines:

- Write clear and easy-to-understand materials
- Place materials in appropriate directories
- Add descriptions for each material in the README
- Provide well-commented code examples
